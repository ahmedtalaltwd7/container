# سِجل | إدارة الشحنات

تطبيق ويب تقدمي (PWA) عربي لإدارة سجلات الحاويات والشحنات على الجهاز. الواجهة مبنية بـ HTML وCSS وJavaScript عادي، وتُحفظ السجلات محلياً في IndexedDB دون حسابات أو خادم أو خدمات خارجية.

## التشغيل

```sh
npm install
npm run dev
```

لإنشاء نسخة الإنتاج وتشغيلها محلياً:

```sh
npm run build
npm run preview
```

يتطلب تثبيت التطبيق والتخزين المؤقت الأولي فتحه مرة عبر HTTPS أو `localhost` مع اتصال متاح. بعد ذلك تُخزّن ملفات الواجهة محلياً ويعمل التطبيق دون اتصال. يتطلب تثبيت PWA في iOS إضافته إلى الشاشة الرئيسية من قائمة المشاركة في Safari.

## البيانات والنسخ الاحتياطي

يحتوي كل سجل على الحقول العشرة المحددة في النموذج فقط. يمكن البحث والتصفية والتعديل والحذف دون اتصال، وتصدير السجلات بصيغة CSV بترميز UTF-8 مع BOM أو إنشاء نسخة JSON واستيراد الملفات السابقة.
